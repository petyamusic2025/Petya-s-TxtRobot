# Petya TxtRobot

Android app dalszövegek TXT-be mentéséhez.

- **Kijelölt szöveg:** a böngészőben kijelölöd a szöveget → ⋮ menü → **Mentés TXT-be**.
- **Előadó összes dala:** az előadó oldalát megosztod a **TxtRobot**-tal (vagy bemásolod a linket), kipipálod a dalokat, és letölti őket külön TXT-kbe, dalonként szünettel.
- **Egy dal:** a dal linkjéből előnézet, javítás, mentés.
- Mentés helye: `Documents/Dalszövegek/<Előadó>/` (a beállításokban módosítható), UTF-8 kódolással.
- Opcionális cirill → latin átírás.

Csak saját, zenekari használatra.
